# Nakshatra Guidance V1
- Uses the same Lahiri sidereal Swiss Ephemeris Moon calculation convention as the existing LiveMoonCalculator.
- Saves birth Nakshatra in the existing BirthProfile.
- Adds Nakshatra Guidance screen with current Nakshatra, Tara Bala, interval and do/avoid guidance.
- Adds separate Upcoming Vipat / Pratyari / Vadha screen for the next 60 days.
- Uses actual computed Nakshatra boundary times, not a static date list.
- Existing functionality/design is preserved; only the new navigation buttons and profile field are added.
